# 3. Descripción de los principales interesados

## INT-01 — Docente / Responsable académico

Supervisa el cumplimiento de los objetivos académicos, entregables, requisitos de la asignatura y criterios establecidos para la evaluación del proyecto.

## INT-02 — Kevyn Leeonardo Velasquez Palomino / Director de Proyecto

Coordina el proyecto, supervisa el avance, organiza actividades, gestiona riesgos y facilita la toma de decisiones.

## INT-03 — EDGARDO GERMAN SERPA CARPENA / Integrante del equipo de desarrollo

Participa en el análisis, diseño, implementación, pruebas y documentación del sistema.

## INT-04 — Responsable de operaciones logísticas

Representa las necesidades relacionadas con los procesos de distribución, planificación de rutas y operación logística.

## INT-05 — Administrador del sistema

Utilizará las funcionalidades administrativas para gestionar usuarios, vehículos, conductores, pedidos y demás información necesaria para la operación.

## INT-06 — Conductor

Es uno de los usuarios operativos principales. Necesita consultar sus rutas, entregas pendientes y alertas relevantes durante el recorrido.

## INT-07 — Cliente de distribución

Proporciona información relacionada con pedidos, horarios preferidos, ubicaciones, referencias y restricciones de entrega.

## INT-08 — Responsable de infraestructura tecnológica

Participa en las decisiones relacionadas con el entorno técnico, disponibilidad, despliegue y funcionamiento de la solución.

## INT-09 — Responsable de pruebas y calidad

Coordina o ejecuta actividades de verificación, validación y pruebas del sistema frente a los requisitos establecidos.
