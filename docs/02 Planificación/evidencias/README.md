## Aclaración sobre el estado de la publicación

La captura `05-release.png` muestra la publicación de Jira con estado **UNRELEASED**, inicio 08/09/2026 y fecha de publicación planificada 30/09/2026. Por tanto, esta imagen demuestra que la versión estaba registrada en la planificación de Jira, no que Jira la hubiera marcado como publicada.

La Release de GitHub `v1.0.0 — Green IT Release` es otro registro: corresponde a la etiqueta Git `v1.0.0` sobre `main` y está publicada en el repositorio. No se deben utilizar ambas capturas como si representaran el mismo estado:

- [Release publicada en GitHub](https://github.com/LeeoGold/EcoLogistics/releases/tag/v1.0.0)
- [Repositorio EcoLogistics](https://github.com/LeeoGold/EcoLogistics)

Si se necesita demostrar la publicación planificada en Jira, será necesario actualizar ese registro en Jira y guardar una nueva captura auténtica; la documentación no debe cambiar el estado de la captura existente.
