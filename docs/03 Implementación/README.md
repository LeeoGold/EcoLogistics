## Estado documental

Esta versión incorpora los resultados comprobados durante la ejecución del Sprint 1: funcionamiento del backend con PostgreSQL, integración frontend-backend, pruebas automatizadas del módulo de vehículos, cobertura del código, comprobaciones técnicas y los gráficos de Burndown/Burnup de Jira.

No se declaran como hechos la aceptación formal del Product Owner, una revisión por Pull Request aprobada ni un despliegue automatizado a staging cuando no se dispone de evidencia de esos eventos.
