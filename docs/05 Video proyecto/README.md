# Video del proyecto — EcoLogística Huancayo

[← Volver al README principal](../../README.md)

## Entrega requerida

- Formato: MP4.
- Duración: aproximadamente 5 minutos (para nivel sobresaliente, objetivo 4:45–5:15).
- Segmento 1: Elevator Pitch, ~1 minuto.
- Segmento 2: demostración funcional, ~4 minutos.
- Guardar el archivo final aquí como `EcoLogistics_Demo_Final.mp4`.

## Estado

El video no está incluido en este paquete: debe grabarse sobre la aplicación desplegada o en ejecución local para que la evidencia audiovisual sea auténtica. No se genera una grabación simulada.

## Preparación

1. Verificar el login y utilizar una cuenta de demostración existente; no mostrar contraseñas ni secretos.
2. Confirmar que frontend y backend están disponibles antes de grabar. Despliegue documentado: `https://ecologistics-frontend.onrender.com` y API `https://ecologistics.onrender.com`.
3. Preparar datos de demostración no sensibles; no mostrar datos personales reales.
4. Cerrar pestañas, notificaciones y ventanas que no formen parte de la demo.
5. Grabar pantalla a 1080p, con audio claro y sin cortes que hagan parecer real una operación no ejecutada.
6. Verificar reproducción y duración del MP4 antes de subirlo al repositorio.

## Guion

Consulta los dos guiones:

- [`guion-video-5-minutos.md`](guion-video-5-minutos.md): texto hablado y acciones para el MP4 obligatorio.
